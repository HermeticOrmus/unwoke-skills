# Using this repo with Cursor

This project includes a **Cursor project rule** so Unwoke mode applies automatically.

## In this repository

1. Open the folder in Cursor.
2. The rule [`.cursor/rules/unwoke.mdc`](.cursor/rules/unwoke.mdc) is committed with `alwaysApply: true`.
3. Confirm under **Settings → Rules**.

## Use the same discipline in another project

**Cursor**: Copy `.cursor/rules/unwoke.mdc` into that project's `.cursor/rules/` directory.

**Other AI tools**: Copy [`CLAUDE.md`](CLAUDE.md) to the project root.

## Note on tone

Unwoke mode is about removing theater, not adding hostility. The discipline is symmetric directness — same level of bluntness for every topic, every group, every position. Not "blunt to politically inconvenient claims, polite to politically convenient ones."

If you find Unwoke responses cruel rather than direct, the calibration is wrong. Re-read [`CLAUDE.md`](CLAUDE.md) section "What this is NOT".
